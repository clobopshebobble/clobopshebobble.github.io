🚗 Real Drive

Drive a 3D car across the real Earth. Paste a free Cesium ion token (no credit card) — or a Google Maps key if you have one. The app detects which. Saved in this browser only.

🆓 Get a free Cesium ion token (≈1 min, no card)
  1. Sign up at ion.cesium.com/signup — free.
  2. Open the Access Tokens tab → copy the default token (starts with eyJ).
  3. Paste it above. You get the real photoreal Google tiles within the free monthly quota. Hit a quota/permission wall? A one-click button drops you to always-free city blocks.
Or use a Google Maps key (needs billing)
  1. console.cloud.google.com → project → enable billing.
  2. APIs & Services → Library → enable “Map Tiles API”.
  3. Credentials → Create credentials → API key, copy it.
